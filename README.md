# bicara-pos-installer

Public release host for **Bicara POS** Windows installers.

Built and published from [`manairalabs/bicara-suite`](https://github.com/manairalabs/bicara-suite) (`pos-electron/`). See latest release for installer downloads.

- `Bicara-POS-Setup-<version>.exe` — production (loads https://pos.bicara.ai)
- `Bicara-POS-Demo-Setup-<version>.exe` — demo (loads https://pos.demo.bicara.ai)

Both are unsigned NSIS installers; Windows SmartScreen will warn on first run.
